# AGENTS.md

Guidance for AI coding agents working in this repository.

## What this is

A set of quantitative-trading learning labs (Chinese prose, Python code). The owner is the
learner. The course is judgement-first: writing code is not the skill being trained; judging
backtests and research claims is.

Each `labs/labNN_*/` has `README.md` (lecture: derivations, intuition, when it breaks, economic
reasoning, with simulated results from `quantlab` quoted inline), `audit.py` (plausible
research code with planted optimistic-bias bugs; the learner reviews and fixes it),
`test_audit.py` (property checks a reviewer would run, not naming the bugs).
`solutions/<lab>.py` is the fixed `audit.py`; `labs/_harness.py` loads `audit.py` by default and
`solutions/` when `QUANT_SOLUTIONS=1`. All reusable implementations live in `src/quantlab/` and
are tested under `tests/`.

When adding an audit bug, mutation-test it: put that single bug back into the solution and
confirm at least one test in `test_audit.py` fails.

## Rules

- **Do not fix `labs/*/audit.py` for the learner** unless explicitly asked. Hints, explanations
  and reviews of their audit notes / fixes / written answers are the default mode of help. When
  asked to review, run `make test LAB=NN` and explain failures in terms of the underlying concept.
- Numbers quoted in a lecture must come from actually running `quantlab` on the synthetic data.
- Lecture figures live in `labs/<lab>/figures/` as SVG, generated by `figures/make.py` (run all
  with `make figures`) from `quantlab` code, and call `quantlab.plotting.use_lecture_style()`
  first: it writes text as real SVG text and sizes figures ~1:1 with the preview width, which is
  what keeps them crisp. Plot labels are English (the images have no CJK font); the Chinese
  explanation goes in the caption.
- Tests run on synthetic data from `src/quantlab/data.py` with fixed seeds: keep them offline,
  deterministic, and under ~30s per lab. Statistical assertions need generous tolerances.
- Any change to a test must still pass with `make check` (reference solutions).
- Keep `pyproject.toml` limited to dependencies: the Docker venv layer is keyed on it. Tool config
  lives in `pytest.ini` and `ruff.toml`. After `uv add`, rebuild images (`hack/devcontainer.sh image`,
  `hack/agent.sh image`).
- `make lint` (ruff) and `shellcheck -x` on `hack/` must pass; the pre-commit hook enforces both.

## Commands

```bash
make test LAB=03        # learner's implementation
make check              # reference solutions, all labs
make lint / make fmt
hack/agent.sh help      # agent container
hack/devcontainer.sh help
```
